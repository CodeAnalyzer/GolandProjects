## 1.3: стоимость полного переобучения

| Стадия | Время |
|---|---|
| Загрузка корпуса (string_agg по req/scn) | 281 мс |
| BuildVocab | ~2.4 с |
| TFIDFMatrix | ~4.9 с (совместно с vocab) |
| **SVD (k=128, gonum Thin)** | **97.1 с** |
| Итого compute | ~102 с |

SVD на матрице 2322×11200 — 97 секунд, существенно выше порога 30 с из задачи 1.3.

**Решение (в рамках контракта, без изменения спеки):** дефолт `lsa_retrain_threshold = 100`
(ранее планировался 0). 100 накопленных изменённых сущностей ≈ 2–3 типичные правки spec.md;
явный `0` в конфиге по-прежнему отключает амортизацию («переобучать при любом изменении
fingerprint»). Значение дефолта не зафиксировано в спеке — калибруется без дельты.

## Замечание

Замер SVD объясняет и выбор «гибрида C»: чистый fingerprint-режим (порог 0) стоил бы
~97 c на каждом прогоне с любой правкой спек; кумулятивный порог амортизирует это
до одного переобучения на серию правок.

## k-тюнинг (Tests/lsaktune): позиция ожидаемой capability при разных k

Один полный SVD (2322 направления), косинусы контрольных запросов при обрезке:

| Запрос → ожидание | k=64 | k=128 | k=192 | k=256 | k=384 | k=512 |
|---|---|---|---|---|---|---|
| «Заметка по клиенту» → legal | #64 | #18 | #16 | #13 | #7 | **#5** |
| «блокировка счёта» → card-block | #4 | #5 | #2 | #3 | **#1** | **#1** |
| «лимит карточки» → limit/correct-limit-register | #3 | #1 | #2 | #1 | #1 | #1 |
| «параметры операции» → operation/operation-sum | #1 | #1 | #1 | #1 | #1 | #1 |

Редкие термины монотонно улучшаются с ростом k; топ-1 для частотных запросов стабилен.
Выбран **k=512** (default, настраивается `lsa_k`). Стоимость SVD от k не зависит
(полное разложение выполняется всегда, k — обрезка хранилища).

## Найденный баг SVD (фикс в этом change)

`SVD()` обрезал Vᵀ до `min(nDocs, nTerms)` колонок: при nTerms=11200 > nDocs=2322
термины с индексом ≥ 2322 выпадали из проекции запроса (заметк idx=4539, арест 2856,
лимит 5601 — все вне). Семантический слой на боевом корпусе фактически не работал
(косинусы 0.0 / шум-артефакты). Фикс: VT на все nTerms + `AlgorithmVersion` в
fingerprint для принудительного переобучения.
