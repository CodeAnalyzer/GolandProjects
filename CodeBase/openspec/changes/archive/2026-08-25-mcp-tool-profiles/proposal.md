# MCP Tool Profiles

## Why

MCP-сервер CodeBase регистрирует все 55 инструментов в одном `tools/list` response размером ~43 KB. Некоторые IDE MCP-клиенты обрезают список инструментов при превышении лимита размера JSON-RPC сообщения, из-за чего ИИ-агент не видит часть инструментов и не может их использовать. Коллега, которому был передан CodeBase, столкнулся с этой проблемой: его IDE обрезала `tools/list`, и агент не использовал CodeBase-инструменты.

Профильная регистрация позволяет запускать один бинарник с разными подмножествами инструментов. IDE может подключить несколько MCP-серверов на один бинарник с разными профилями, каждый из которых укладывается в лимиты. Профили можно включать/выключать независимо.

## What Changes

- Добавлен необязательный флаг `--profile` на команду `codebase mcp`. Без флага сохраняется текущее поведение — регистрируются все 55 инструментов.
- При указании `--profile=<name>` регистрируется только подмножество инструментов, релевантное профилю, плюс базовые (`ping`, `health`, `stats`, `read_more`).
- Доступные профили:
  - `query` — базовые + query инструменты (~30 инструментов).
  - `rti` — базовые + RTI инструменты (~17 инструментов).
  - `trc` — базовые + TRC инструменты (~14 инструментов).
  - `review` — базовые + review инструмент (~5 инструментов).
- При неизвестном профиле возвращается ошибка с перечислением доступных профилей.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `mcp-server/mcp-transport-tools` — добавляется требование профильной регистрации инструментов.

## Impact

- `cmd/mcp.go` — добавление флага `--profile`, передача в `RunStdio`.
- `internal/mcp/server.go` — `RunStdio` принимает параметр `profile`, фильтрация registry по профилю.
- `internal/mcp/registry.go` — добавление маппинга профиль → список имён инструментов, функция фильтрации `buildToolRegistryForProfile`.
- `internal/mcp/types.go` — без изменений.
- `cmd/root.go` — обновление help-текста команды `mcp` и `isMCPMode` (без изменений логики).
- Конфигурация IDE — возможность подключить несколько MCP-серверов на один бинарник с разными `--profile`.
