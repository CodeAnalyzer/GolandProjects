# Дельта: spec-search — LSA-корпус при мультиветочной индексации

## ADDED Requirements

### Requirement: LSA-корпус при мультиветочной индексации

При индексации нескольких веток продуктов система SHALL формировать корпус
LSA-документов без раздувания параллельными ветками: документ capability
включается из default-ветки (`is_default = true`); capability, встречающаяся
только в не-default ветках, включается из самой свежей из них; документы с
идентичным содержимым схлопываются. Правило применяется и к fingerprint
корпуса: появление второй ветки с теми же спеками НЕ SHALL само по себе
менять fingerprint и принудительно переобучать модель.

#### Scenario: Спека в develop и в SP-ветке

- **GIVEN** capability, прочитанная из develop и из `fa-contracts-11-01-7` с идентичным содержимым
- **WHEN** формируется LSA-корпус
- **THEN** в корпусе один документ этой capability из default-ветки

#### Scenario: Спека только в SP-ветке

- **GIVEN** capability, существующая только в `fa-contracts-11-01-7`
- **WHEN** формируется LSA-корпус
- **THEN** документ включён из этой ветки
