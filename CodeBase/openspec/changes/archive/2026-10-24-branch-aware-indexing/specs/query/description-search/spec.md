# Дельта: description-search — корпус описаний при мультиветочной индексации

## ADDED Requirements

### Requirement: Корпус описаний при мультиветочной индексации

При индексации нескольких веток продуктов система SHALL формировать корпус
desc-LSA без раздувания: документ сущности (SQL-процедура, API-контракт)
включается из default-ветки; сущность, встречающаяся только в не-default
ветках, включается из самой свежей из них; документы с идентичным
`body_hash` схлопываются в один. Появление второй ветки с побайтово теми же
сущностями НЕ SHALL само по себе менять fingerprint корпуса и принудительно
переобучать модель.

#### Scenario: Процедура в двух ветках

- **GIVEN** процедура `MyProc` с идентичным телом и описанием в develop и в `fa-payments-11-01-21`
- **WHEN** формируется корпус описаний
- **THEN** в корпусе один документ `MyProc` из default-ветки

#### Scenario: Процедура только в релизной линии

- **GIVEN** процедура `NewProc`, существующая только в `fa-payments-11-01-21`
- **WHEN** формируется корпус описаний
- **THEN** документ `NewProc` включён из этой ветки
