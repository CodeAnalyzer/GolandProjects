# Дельта: branch-sources (параллельная git-детекция)

## MODIFIED Requirements

### Requirement: Discovery источников в init/update

Система SHALL при каждом `init`/`update` перед обходом файлов проходить
непосредственных детей `root_path`: для каждого git-каталога выполнять
git-детекцию, upsert `ds_products` (по basename remote) и `ds_products_branch`
(по продукту + `branch_key`), и строить карту «префикс пути → источник».
Количество вызовов git CLI SHALL быть конечным (по одному набору вызовов на
каталог, с кэшем на время скана).

Git-детекция каталогов SHALL выполняться параллельно пулом воркеров; размер
пула SHALL равняться эффективному значению параллельности индексации
(`indexer.parallel` из конфигурации либо флаг `-j`, по умолчанию 4). Кэш
детектора MUST быть потокобезопасным. Результат discovery (карта источников,
строки `ds_products`/`ds_products_branch`, метки default-веток) SHALL быть
идентичен результату последовательной детекции тех же каталогов и не зависит
от порядка завершения воркеров.

#### Scenario: Появление каталога ветки

- **GIVEN** индекс с одним источником `fa-contracts` (develop) и новый каталог `fa-contracts-11017` на `FA-Contracts-11-01-7-SP`
- **WHEN** выполняется `codebase update`
- **THEN** в `ds_products_branch` две линии продукта `fa-contracts`: `develop` и `fa-contracts-11-01-7`

#### Scenario: Отсутствие git в PATH

- **GIVEN** среда без установленного git и дерево с git-каталогами
- **WHEN** выполняется `codebase update`
- **THEN** выводится понятная ошибка либо git-каталоги обрабатываются по эвристике пути без аварийного завершения

#### Scenario: Параллельная детекция 80 каталогов

- **GIVEN** корень с 80 git-каталогами разных продуктов и `indexer.parallel = 12`
- **WHEN** выполняется discovery
- **THEN** все 80 каталогов задетектированы: карта источников и строки `ds_products_branch` идентичны результату последовательной детекции
- **AND** детекция выполняется конкурентно: максимум одновременно выполняющихся детекций не превышает размер пула (12) и достигает его при достаточном числе каталогов

#### Scenario: Пул из одного воркера

- **GIVEN** корень с git-каталогами и запуск с `-j 1` (или явный `indexer.parallel = 1`)
- **WHEN** выполняется discovery
- **THEN** детекция выполняется по одному каталогу за раз с тем же итоговым результатом
