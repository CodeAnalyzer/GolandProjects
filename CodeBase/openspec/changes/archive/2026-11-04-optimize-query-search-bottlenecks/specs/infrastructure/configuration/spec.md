## MODIFIED Requirements

### Requirement: Настройки query лимитов

Система SHALL поддерживать настройку лимитов query через секцию `[query]` с параметрами default_limit (по умолчанию 100) и max_limit (по умолчанию 1000). Дополнительно секция `[query]` SHALL поддерживать параметр sql_fragment_match_cap (по умолчанию 50000) — потолок числа кандидатов поиска sql-fragment; значение `0` отключает ограничение; отрицательное значение — ошибка загрузки конфигурации с указанием имени параметра.

#### Scenario: Кастомный лимит

- **GIVEN** конфигурация с `[query] default_limit = 50`
- **WHEN** выполняется `query symbol --name MyProc` без флага `--limit`
- **THEN** возвращено не более 50 результатов

#### Scenario: Потолок кандидатов sql-fragment по умолчанию

- **GIVEN** конфигурация без `sql_fragment_match_cap`
- **WHEN** выполняется `query sql-fragment --text <сверхширокий шаблон>`
- **THEN** обход кандидатов ограничен 50000 совпадениями, ответ помечен усечением

#### Scenario: Нулевой потолок отключает ограничение

- **GIVEN** конфигурация с `[query] sql_fragment_match_cap = 0`
- **WHEN** выполняется `query sql-fragment --text <сверхширокий шаблон>`
- **THEN** ограничение кандидатов не применяется

#### Scenario: Отрицательное значение отклоняется

- **GIVEN** конфигурация с `[query] sql_fragment_match_cap = -1`
- **WHEN** загружается конфигурация
- **THEN** загрузка завершается ошибкой с упоминанием `sql_fragment_match_cap`
