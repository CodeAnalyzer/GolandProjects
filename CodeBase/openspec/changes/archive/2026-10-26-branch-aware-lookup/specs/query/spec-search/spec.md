# Дельта: spec-search — дедупликация веток в лексическом слое

## ADDED Requirements

### Requirement: Дедупликация копий из веток в лексическом слое

Лексический слой поиска по спекам SHALL схлопывать копии одного
артефакта (capability, требование, сценарий, usecase — уровень и
естественное имя), отличающиеся только веткой одного продукта
(checkout'ы релизных линий со своими `openspec/`), по приоритету
default-ветки — по тому же принципу, что «LSA-корпус при мультиветочной
индексации»; совпадение SHALL сообщать использованную конфигурацию/ветку.
Разные артефакты одной capability (несколько требований/сценариев) и
совпадения разных продуктов SHALL оставаться отдельными строками — состав
результатов на одно-веточном индексе не меняется.

#### Scenario: Capability в develop и SP-линии

- **GIVEN** capability `contract-lifecycle` в spec-конфигурациях develop и `11-01-7` одного продукта
- **WHEN** выполняется поиск, матчатся обе копии
- **THEN** в exact-секции одна строка `contract-lifecycle` с пометкой develop-конфигурации

#### Scenario: Разные продукты не схлопываются

- **GIVEN** одноимённая capability в продуктах fa-contracts и fa-payments
- **WHEN** выполняется поиск
- **THEN** возвращены отдельные строки для каждого продукта
