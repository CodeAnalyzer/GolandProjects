# Дельта: description-search — дедупликация веток в результатах

## ADDED Requirements

### Requirement: Дедупликация копий из веток в результатах поиска

Exact-слой поиска по описаниям (и сборный гибридный результат) SHALL
возвращать не более одной строки на сущность одного продукта: строки,
отличающиеся только веткой одного продукта, схлопываются по приоритету
default-ветки — по тому же принципу, что корпус «Корпус описаний при
мультиветочной индексации»; выбранная строка SHALL содержать `product` и
`branch_used`. Описания разных продуктов остаются отдельными строками.
На одно-веточном индексе дедупликация не SHALL изменять состав результата.

#### Scenario: Описание процедуры в двух ветках

- **GIVEN** описание процедуры `MyProc` в develop и в `11-01-7` одного продукта, совпадающее по тексту запроса
- **WHEN** выполняется `desc-search` по словам описания
- **THEN** в ответе одна строка `MyProc` продукта с `branch_used` = develop

#### Scenario: Одно-веточный индекс без изменений

- **GIVEN** одно-веточный индекс
- **WHEN** выполняется `desc-search`
- **THEN** состав результата идентичен прежнему (дедупликация не удаляет строки)
